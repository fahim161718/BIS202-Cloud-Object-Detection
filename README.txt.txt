Project Title:
Implementing an Image Object Identification System on AWS Using AWS Lambda, API Gateway and Amazon S3

Project Description:
This project implements a serverless image object identification system using Amazon Web Services (AWS). The solution integrates Amazon API Gateway, AWS Lambda, Amazon S3, IAM and CloudWatch. API Gateway receives requests and forwards them to a Lambda function which performs object identification and stores results in Amazon S3. The system demonstrates serverless cloud architecture and cloud service integration.
