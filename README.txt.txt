Project Title:
Implementing an Image Object Identification System on AWS Using YOLOv5, Lambda, API Gateway and Amazon S3

Repository:
https://github.com/fahim161718/BIS202-Cloud-Object-Detection

Description:
This project implements a serverless image object identification system using AWS cloud services. Images are uploaded to Amazon S3 and processed using a YOLOv5 object detection model through AWS Lambda. API Gateway provides external access to the detection service while results are stored in Amazon S3.
